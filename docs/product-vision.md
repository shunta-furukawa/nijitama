# にじのたまご
家庭の子どもが「もうひとつ橋をかけたい」と自分から島を訪れる学びの場。橋の長さが変わる操作そのものを、小数の位取りに対応させる。正解まで何度でも石を動かせる。時間切れ、順位表、課金は設けない。

赤は物語、青は数と論理、緑は自然、黄は地理と歴史、紫は交流を受け持つ。５匹とも最初から仲間。学習を終えたときに世界に変化が起きる。現在は青いドラゴンの翼が初回完了後に広がる。将来は学年ごとの到達目標を満たしたときに大きく姿が変わる。

主対象は日本の小学生。学校の学年はプロフィール情報とし、復習と先取りの両方を認める。家族内でも達成度を競わせず、保護者は子どもごとの最近の記録から、いっしょに遊ぶ単元を選ぶ。
