# 教育内容の管理
小学4年の「数と計算」のうち、百分の一の位までの小数の構成を扱う。単元全体や学年全体を修了したという判定は行わない。[文部科学省『小学校学習指導要領（平成29年告示）解説 算数編』](https://www.mext.go.jp/content/20211102-mxt_kyoiku02-100002607_04.pdf)

curriculum/islands.json に版、学校段階、教科、対象学年、領域、単元ID、目標、活動ID、問題数、完了報酬、将来の進化条件を保持する。学習者自身の学年と単元の対象学年は独立している。世界は表示上の区分で、生活科や外国語活動の追加時は正式な教科・活動と世界との対応を定義する。

橋では1、0.1、0.01の石を各0〜9個置き、目標の長さと一致させる。生成範囲は0.02〜1.99、1セッション5問は重複しない。内部では百分の一単位の整数で表す。セッションの問題列、step、提出値から各問題と各位の回答を再現できる。出題の変更時は新しい版付き単元IDにして既存履歴の意味を保つ。

理解度は同じ学習者・単元の直近8回答の平均（整数切り捨て）。自力正解100、ヒントを使った問題の正解50、誤答0。同じ橋での再挑戦も1回答と数える。記録のない場合は初期値0。65未満は保護者が確認する候補とする。教育測定で検証済みの尺度ではない。学習時間は回答間隔の合計で、各回答は放置時間を考慮して最大180秒に丸める。

同じ位置表記を使う活動は生成範囲や目標の差し替えを優先する。異なる操作を要する次の単元を加えるときに、単元IDを受け取るAPIと活動別の表示・評価の振り分けを導入する。学年到達による進化は報酬残高だけで判定しない。
